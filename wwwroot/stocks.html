SECURE CONNECTION

IBKR gateway setup

This app does not store your Interactive Brokers username or password. Run Client Portal Gateway on a private host, sign in through its browser page, complete MFA, and configure IBKR_GATEWAY_BASE_URL to a URL this server can reach. Azure cannot call a gateway running only on your home computer unless you provide a secure private connection.
